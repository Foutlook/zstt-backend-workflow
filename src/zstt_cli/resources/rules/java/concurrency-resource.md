# 并发与资源生命周期检查表

## 触发条件

本次范围包含锁、线程池、异步任务、定时器、重试、共享状态、缓存、文件/流、连接、内存或 GC 问题。

## 检查项

- 锁的所有者、粒度、获取顺序、等待时间和释放路径是否明确。
- 共享状态的可见性、原子性和线程安全责任是否明确。
- 中断、取消、超时、重试上限和失败结果是否保持既有语义。
- 流、连接、线程池、定时器和监听器是否在所有路径正确关闭或注销。
- 缓存和集合是否存在无边界增长，生命周期是否与业务对象一致。
- 性能或内存优化是否有修改前基线、修改后同口径数据和回归验证。

## 例子

把锁等待从 30 秒改为 3 秒会改变失败窗口；它不是单纯性能优化，必须作为业务行为变化单独审批。
